# 단계별 구현 기록

전체 명세를 기준으로 기존 정적 MVP를 확장한다. 서버·외부 DB·참가자 관리(P2)는 추가하지 않는다.

## 1단계 — 데이터 구조 (완료)

- `schemaVersion: 1`, 중앙 migration, category와 독립적인 round, 사용·검수 상태, 난이도, 출제자, 인정답안·판정메모·생성/수정 시각.
- `timeLimit`이 기준이며 기존 `seconds`는 호환용으로 함께 저장한다.
- 기존 localStorage 키와 JSON 백업을 유지한다. 신규 버전/손상 데이터는 자동 덮어쓰지 않는다.
- 기존 ID, 순서, 제목, 본문, 정답, 해설, 이미지, 진행 메모와 빈 설정값을 보존한다.
- 검증: 6개 테스트 통과(설정 회귀 포함), JS 구문 검사, 배포 빌드 성공.
