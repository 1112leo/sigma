# 시그마 수학 골든벨 프레젠테이션 콘솔 (`/goldenbell/run`)

PPT 대신 사용하는 오프라인 우선 골든벨 진행 사이트입니다. 한 대의 진행 노트북과 HDMI 프로젝터 구성을 기준으로 합니다.

## 주요 기능

- PIN으로 잠긴 진행자 콘솔
- 조작 기능이 없는 읽기 전용 프로젝터 화면
- 안내 화면과 문제를 섞는 행사 구성(sequence), 현재 위치 복원, 이전/다음 항목 이동
- 기본 안내 화면 14종과 사용자 화면의 제목·부제·설명·강조 문구·색상 편집
- 문제별 제한시간, 시작/일시정지, ±5초, 초기화
- 정답 공개 시 해설 표시, 프로젝터에는 나오지 않는 진행자 메모
- 문제 추가·수정·삭제·순서 이동, 문제/정답/ID 검색
- 유형과 독립적인 라운드, 출제자·난이도·사용/예비/미사용·검수 상태 필터와 통계
- 진행자 전용 인정 답안·판정 메모·진행 메모
- 문제별 그림·사진 첨부와 프로젝터 자동 배치
- 행사명, 일시, 장소, 각 슬라이드 문구 편집
- 브라우저 자동 저장과 JSON 백업/복원
- 진행자–프로젝터 상태 동기화
- 긴급 안내·예비문제 즉시 송출/다음 삽입·직전 화면 복귀·진행 안전 잠금
- 행사 경과/잔여 시간, 라운드 진행, 무효 처리와 로컬 진행 로그
- 로컬 KaTeX 수식, JSON/CSV 문제 일괄 가져오기, 행사 사전 점검과 시작 전 체크리스트

## 실행

저장소 루트(`sigma`)에서 localhost에만 연결되는 서버를 열어주세요.

```bash
python3 -m http.server 8080 --bind 127.0.0.1
```

브라우저에서 `http://127.0.0.1:8080/goldenbell/run/`을 엽니다.

1. 첫 접속에서 4~12자리 숫자 진행 PIN을 만듭니다.
2. `프로젝터 열기`를 눌러 읽기 전용 창을 엽니다.
3. 새 창을 프로젝터 화면으로 옮기고 `전체 화면`을 누릅니다.
4. 문제 편집 후 `행사 구성`에서 사용할 문제와 안내 화면을 배치합니다.
5. 실시간 진행에서 이전/다음 항목과 정답 공개를 조작합니다.

사용 문제로 자동 구성하면 예비·미사용 문제는 제외됩니다. 예비 문제는 경고 확인 후 수동 추가할 수 있습니다. 문제 목록의 순서 변경은 이미 만든 행사 구성에 영향을 주지 않습니다.

## 단축키

- `Space`: 타이머 시작/일시정지
- `A`: 정답 공개/숨기기
- `←` / `→`: 이전/다음 행사 항목 (정답 공개는 별도)
- `R`: 타이머 초기화
- 프로젝터 창의 `F`: 전체 화면

## 기본 문제 슬롯

- 기본문제 35
- 고난도 10
- 패자부활 5
- 등수결정 10

기본 슬롯은 문제 편집에서 자유롭게 수정하거나 삭제할 수 있습니다.

## 데이터와 검증

- `schemaVersion: 3`. 구형 문제/백업은 자동 변환하며 기존 localStorage 키를 유지합니다.
- `timeLimit`이 기준이고 `seconds`는 구형 백업 호환을 위해 함께 저장합니다.
- 슬라이드의 빈 문구는 빈칸으로 저장합니다. 더 최신 버전 또는 손상된 데이터는 기본값으로 덮어쓰지 않습니다.
- 최대 문제 500개, 기본 포함 안내 화면 200개, 행사 항목 2,000개입니다.
- 이 폴더에서 `npm test`, `npm run build`로 회귀 테스트와 빌드를 실행합니다.
- 테스트용 PIN은 1111을 사용합니다. 배포 코드에 기본 PIN을 고정하지는 않습니다.

현재 명세 1~5단계까지 구현했습니다. P2 참가자·탈락·순위 관리는 구현하지 않았습니다.

긴급 안내와 예비문제는 원본 행사 구성을 바꾸지 않습니다. `직전 화면 복귀`는 남은 시간을 보존하고 타이머를 멈춘 상태로 돌아갑니다. 타이머 작동 중 이동은 안전 잠금으로 확인하며, 긴급 안내는 즉시 전환됩니다. 임시 진행 중 원본 구성을 편집하려면 `임시 진행 정리`를 먼저 사용하세요.

## 수식과 문제 가져오기

문제·정답·해설에 `$x^2$`(인라인), `$$x^2+y^2=1$$`(별도 줄)를 사용하세요. 달러 문자 자체는 `\$`로 입력합니다. 잘못된 수식과 외부 링크/이미지 명령은 원문과 작은 오류 경고로 표시됩니다. 사진과 함께 사용할 수 있습니다.

KaTeX 0.18.4와 폰트는 `vendor/katex`에 포함되어 CDN을 사용하지 않습니다. 인터넷이 끊긴 현장에서는 프로젝트를 내려받아 위의 로컬 서버로 실행하세요. 배포 주소의 오프라인 새 접속·새로고침까지 보장하는 서비스워커는 포함하지 않습니다. JSON 백업은 데이터이며 웹앱 프로그램을 대신하지 않습니다.

`행사 점검·가져오기`에서 파일을 선택하거나 데이터를 붙여넣고 `파싱·미리보기`를 누릅니다.

- JSON: 문제 객체 배열 또는 `{ "questions": [...] }`. 새 문제는 ID 생략 시 한 번 생성합니다.
- CSV: 첫 줄은 필드명입니다. 쉼표·줄바꿈이 포함된 셀은 큰따옴표로 감싸고, 셀 안 큰따옴표는 두 번 씁니다. 빈 round는 미지정입니다.
- 추가: 기존 ID와 겹치면 차단합니다. ID 업데이트: 같은 ID는 변경하고 없는 ID는 추가합니다. 생략한 기존 필드는 사진·메모·작성 시각·순서와 함께 보존됩니다.
- 전체 교체: 확인 후 문제와 임시 진행 기록을 교체합니다. 행사 설정·안내 화면·원본 구성은 유지됩니다. 누락 참조가 있으면 행사 구성을 고치거나 사용 문제로 자동 구성하세요.
- 적용 전 전체 JSON 백업을 내려받고, 검증 오류·사진 디코딩 오류·저장 실패 시 적용하지 않습니다. 모든 가져오기는 타이머를 멈추고 복귀 기록까지 정답 공개를 해제합니다.

예시 CSV:

```csv
id,category,round,question,answer,explanation,timeLimit,usageStatus,reviewStatus
Q001,basic,main1,"$1+1$의 값은?",2,,30,active,final
```

자동 점검은 문제/정답/시간, 검수·구성 누락, 중복 ID·중복 배치, 누락 참조, 패자부활/최종 라운드, 사진 디코딩, 수식 오류를 확인합니다. 점검 후 데이터가 바뀌면 다시 실행하세요. 프로젝터 연결과 가독성은 체크리스트를 보며 직접 확인해야 합니다.

## 그림·사진 문제

문제 편집에서 `문제 그림·사진`을 선택하면 사진이 프로젝터 크기에 맞게 자동 압축됩니다. JPG, PNG, WebP를 권장합니다.

- 문제당 사진 한 장을 넣을 수 있습니다. 여러 그림은 미리 한 장으로 합쳐주세요.
- 사진과 사진 설명은 문제 데이터에 포함되어 JSON 백업·복원 시 함께 이동합니다.
- 브라우저 저장 한계 때문에 사진이 많은 경우 원본보다 가벼운 이미지를 사용하세요.

## 보안 및 데이터 주의사항

진행 PIN은 진행 노트북의 우발적인 조작·노출을 막는 `브라우저 로컬 잠금`입니다. 정적 웹앱이므로 인터넷에 공개했을 때의 서버 인증을 대체하지 않습니다.

- 배포본도 사용할 수 있지만, 진행자 콘솔과 프로젝터 창은 같은 노트북·같은 브라우저에서 열어야 실시간으로 연결됩니다.
- 다른 노트북으로 교체할 때는 미리 저장한 JSON을 불러오고 새 PIN을 설정하면 됩니다.
- 프로젝터는 진행자가 연 세션 주소로만 연결되며, 문제 화면에서는 현재 문제와 공개된 정답만 별도로 전달됩니다. 진행 메모는 전달되지 않습니다.
- PIN 인증은 브라우저 탭을 닫으면 종료됩니다.
- PIN을 잊었을 때는 브라우저의 사이트 데이터를 지워야 하므로, 행사 전에 JSON 백업을 받아두세요.
- 백업 JSON에는 미공개 정답과 진행 메모가 평문으로 포함됩니다. 안전한 장소에 보관하세요.

배포 주소를 아는 사람이 사이트 자체에는 접근할 수 있으므로 URL은 진행팀 안에서만 공유하세요. 별도 PC 프로젝터, 원격 참가자, 인터넷 공개용 실제 접근 통제가 필요하면 서버 인증과 실시간 동기화 계층이 필요합니다.
