# 기존 발표 디자인 복원

- Stage 3 공통 렌더러가 우회했던 기존 대기·오프닝·안내·휴식·마침 디자인을 다시 연결했다.
- 기본 화면은 기존 배경, Σ 워터마크, 영문 머리말, 상태 표시, 대기 날짜·장소, 안내 번호 목록을 사용한다. 원래 기본 프리셋 외에 선택한 색상은 그대로 적용한다.
- 제목·부제·설명·강조의 편집값과 명시적 빈칸은 유지한다. 새 사용자 화면은 기존 공통 렌더러를 유지한다.
- 공개 상태에 검증된 디자인 분류(template)만 추가한다. 문제 메모·인정 답안·다음 항목 등 비공개 데이터는 추가하지 않는다.
- 빠른 슬라이드 선택은 Stage 4 임시 송출·복귀를 사용한다. 원본 행사 순서와 데이터를 바꾸지 않으며 타이머는 복귀 후 수동 재개한다.
